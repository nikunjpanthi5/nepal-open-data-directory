# Nepal-related APIs

This directory indexes APIs that provide data or services relevant to Nepal. It does not host or operate the listed APIs.

## API catalogue

No API entries have been reviewed and published yet. Add entries only after checking the provider's documentation.

## Recommended entry fields

| Field | Description |
|---|---|
| API name | Official name of the service |
| Provider | Organization operating the API |
| Description | What information it provides |
| Documentation | Official API documentation |
| Base URL | API base endpoint, if public |
| Authentication | None / API key / OAuth / other |
| Rate limits | State only if documented |
| Coverage | Geographic and temporal coverage |
| License / terms | API terms and data reuse conditions |
| Last verified | YYYY-MM-DD |

## Submission

Follow the [contribution guidelines](../CONTRIBUTING.md). Never commit API keys, access tokens, passwords, or other secrets.
