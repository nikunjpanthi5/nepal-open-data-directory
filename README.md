# 🇳🇵 Nepal Open Data Directory

**Discover. Explore. Research. Build.**

A community-driven collection of open datasets, APIs, and research resources related to Nepal.

Our goal is to make Nepal-related data easier to discover, access, understand, and use for research, education, data science, and innovation.

## 🎯 Project Goals

- Centralize the discovery of Nepal-related open datasets.
- Help students and researchers find useful data.
- Support AI, machine learning, and data science research.
- Encourage open-source collaboration.
- Improve dataset documentation and accessibility.
- Promote responsible and transparent data reuse.

## 📋 Dataset Information

Where available, dataset entries should include:

- Dataset name and description.
- Original source and access link.
- Category and geographic coverage.
- Data format and temporal coverage.
- License and reuse restrictions.
- Last verified date.
- Potential research and analytical applications.

Dataset information should be verified against its original source. Unknown licensing conditions must be clearly marked rather than assumed to be open.
