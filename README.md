# 🇳🇵 Nepal Open Data Directory

**Discover. Explore. Research. Build.**

A community-maintained index of datasets, APIs, and research data resources about Nepal.

The goal is simple: make Nepal-related data easier to discover, assess, cite, and reuse for education, public-interest research, data science, and innovation.

> **Status:** This directory is being built. Entries are added as they are reviewed; an empty category means that no entry has been published there yet. Always confirm availability and reuse terms at the original source.

## What belongs in this directory?

We include resources that are about Nepal or are useful for Nepal-focused work, including:

- Official statistics and government data.
- Research datasets from universities and institutions.
- Geospatial, environmental, economic and social data.
- Nepali language, speech, OCR and other AI/ML resources.
- APIs that provide documented access to relevant data.

This is an **index and discovery project**, not the original publisher or data owner. Where redistribution is permitted and useful, files may be included in the repository with clear attribution. Otherwise, entries should link to the original source.

## Dataset quality and metadata

Each entry should include as many of these fields as the source supports:

| Field | Purpose |
|---|---|
| Title and description | Identify the resource and explain its contents |
| Publisher | Credit the organization or research group |
| Category | Make the resource discoverable |
| Geographic and temporal coverage | Explain where and when the data applies |
| Format | CSV, XLSX, JSON, PDF, GeoJSON, API, etc. |
| Original source URL | Link to the publisher's page |
| Download or access URL | Link to the file or API, when available |
| License | State the actual reuse terms; use **Unknown** if not stated |
| Last verified | Record when the link and metadata were checked |

Do not infer that a dataset is openly licensed merely because it can be downloaded. Check the original terms before copying, modifying, or redistributing it.

## Contributing

Contributions are welcome from students, researchers, developers, public institutions and anyone who can improve the directory.

1. Find a Nepal-related dataset or API from a credible source.
2. Check that the link works and record the original publisher.
3. Read the license or terms of use. If unclear, write **Unknown** and link to the terms page.
4. Add the entry to the relevant category page and the machine-readable catalogue.
5. Follow the [contribution guidelines](CONTRIBUTING.md).

Please do not commit private, personal, confidential, or unlawfully obtained data. Do not upload third-party files unless redistribution is permitted.

## Project principles

- **Source-first:** credit the original publisher and link to the canonical source.
- **Transparent licensing:** never guess or silently replace a license.
- **Useful metadata:** prefer accurate, complete records over large unverified lists.
- **Reproducibility:** keep metadata structured and consistent.
- **Community-led:** welcome corrections, additions and link checks.
